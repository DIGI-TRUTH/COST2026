Annual cycle

StageInstruments and output
1. StudyQ0 competence & needs questionnaire (M1–2, then yearly) · re-run of the matrix scripts · online refinement meetings per package → Assessment vN
2. PlanningAnnual plan from the assessment: STSM calls and priority rules, Virtual Mobility, Training Schools, indicator targets · Core Group proposes, MC approves
3. OrganisationPackage teams set up · calls opened · Training School programme · initiatives logged in the progress panel
4. ExecutionSTSMs, Virtual Mobility, Training Schools, WG meetings · Q-post questionnaire after each activity
5. ControlSix-monthly: Q-pulse · online control meeting · dashboard review · triggers G1–G9 → annual report and next Study

Adjustment triggers

#Trigger (dashboard / questionnaires)Planned adjustment

G4Low uptake of a package (applications below the MC threshold)Merge with a related package or switch to Virtual Mobility

G7Low usefulness or learning reported in Q-postRevise the activity format (length, level, language)
G8Results not reaching stakeholders (stakeholder survey)Adjust the policy-translation activities — the analysis → policy path asked by CER 2025
G9Self-declared level 3 without verified evidence (Q0 / Q-pulse)Request evidence; until then the competence is recorded as ‘self-declared’
